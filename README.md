# Creality K1C Gantry

This project contains a set of custom mechanical parts and assemblies designed for the Creality K1C 3D printer. The repository focuses on gantry and motion-system improvements, including reinforced structural components, belt tensioning hardware, motor mounts, idlers, pulleys, and carriage/joint pieces used to improve alignment, rigidity, and overall printer reliability.

The models are provided as CAD and manufacturing files, including STEP, assembly, and parameterized design files. They are intended for users who want to modify or upgrade their K1C printer with stronger, more precise, or more serviceable parts.

## Project purpose

The goal of this project is to provide printable and machinable hardware that can be used to:

- improve gantry stiffness and stability
- improve belt alignment and tensioning
- refine XY motion geometry and component fit
- replace stock parts with more robust or customized alternatives
- support experimentation and iteration on the K1C platform

## Included components

This repository includes multiple parts and subassemblies, such as:

- gantry and carriage components
- left/right XY joint assemblies
- belt tensioners
- stepper motor mounts
- idler pulleys and pulley-related parts
- structural brackets and retainers
- washers and supporting hardware
- complete assembly layouts for inspection and modification

## File types

The project contains a mix of CAD-related files, including:

- `.stp` – STEP geometry files
- `.par` – CAD/part files
- `.asm` – assembly files
- `.cfg` – configuration files
- `.log` – build or generation logs

These files are useful for opening in CAD software, reviewing fit and motion relationships, modifying dimensions, or exporting parts for fabrication.

## Recommended use

1. Open the assembly files to understand how the parts relate to each other and to the printer frame.
2. Review the relevant variants (for example, V2 versions or left/right mirrored parts) before printing or machining.
3. Print or machine the selected parts with appropriate material and tolerances.
4. Test fit before full installation, especially for bearing, pulley, and belt interfaces.
5. Tune belt tension and alignment after installation to ensure smooth motion.

## Notes

This is a community-driven hardware project. Parts may be experimental, require iteration, and may need adjustment depending on printer revision, material choice, machine tolerances, and intended use case.

Before using any modified or custom part in a production setup, verify fit and mechanical performance carefully. The files are provided as-is for personal fabrication and experimentation.

## Summary

Creality K1C Gantry is a collection of mechanical enhancement files for improving the frame, motion system, and hardware of the Creality K1C printer. It is designed for makers, tinkerers, and advanced users who want to refine the printer with custom, stronger, and better-tuned parts.
